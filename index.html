Dynamic Tool Registration

Register or remove tools at runtime using structured JSON configurations. Support for OpenAPI, GraphQL, CLI-based tools, and nested MCP servers.

Multi-Auth Support

Handle multiple authentication strategies including OAuth, Bearer tokens, Basic auth, and custom authentication flows.

🔄

Unified Interface

Expose all tools across registered servers through a single, unified MCP-compliant interface with automatic request forwarding.

Health Monitoring

Built-in health monitoring and status tracking for all member servers with automatic failover and recovery.

CLI & API

Launch via CLI or integrate via API. Support for both HTTP and stdio modes with flexible configuration options.

Chatbot Ready

Includes a chatbot agent service with UI demo for easy integration and testing of your MCP tools.
